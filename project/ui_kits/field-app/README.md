# Field app · Canvasser authorisation

Mobile ("Field") surface: single column, 48px touch targets, Ink top bar. Shows how a Canvasser (`VOLUNTEER`) proves authority offline with a signed capability token.

Flow: My authorisation (token card) → Households (scope-locked list for VD 10930012) → Capture (POPIA consent gate, outcome, save or queue offline). Demo controls toggle connectivity and simulate a revocation enforced on reconnect.

All names, IDs and addresses are fictional.
