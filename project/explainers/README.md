# Election-COS explainer videos

Ten short explainers, one HTML file each. Words are verbatim from src/site/explainerVideos.ts.

To get MP4s: open a file in Claude Design, choose 16:9 or 9:16 in Tweaks, then Share → Export → Video.
To preview offline: open index.html in a browser (needs internet for fonts and React).
