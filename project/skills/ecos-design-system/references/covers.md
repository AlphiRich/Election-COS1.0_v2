# ECOS print covers

Five A4 front + back cover designs live in the design-system project at `templates/covers/` (shared `covers.css`, QR codes in `assets/qr/`). Sizes are in container-query units so each page fits A4 and Letter.

| # | Design | Use for |
|---|---|---|
| 01 | Classic — Paper, typographic (the edited source cover) | Research reports |
| 02 | Ink field — Amber rule, four-up metadata | War Room briefings, internal |
| 03 | Ledger — Ink masthead band, 12-col grid, giant mono code | Ward data packs |
| 04 | Split — Ink spine + Amber seam, statutes ledger | Compliance handbooks |
| 05 | Photo — full-bleed civic photo over Ink | Field guides, public-facing |

Rules: document class is the headline; document code `ECO-DOC-NNNN-TYPE-YYYY` in IBM Plex Mono; tagline is Roadmap #8A6A2A on Paper, Amber only on Ink; QR codes always dark-on-light with quiet zone.
